# Ven

Ven adds CurseForge to the Modrinth App.<br>
Ven is not affiliated with or endorsed by Modrinth or CurseForge/Overwolf.

## Install

Requires windows and the Modrinth app in its default location.

1. Download the latest Ven release.
2. Quit the Modrinth App.
3. Run `VenInstaller.exe` and click **Install**.
4. Start the Modrinth App from its Start menu or desktop shortcut.

Ven only loads when the app is started from those shortcuts. To uninstall, run `VenInstaller.exe` and click **Remove**.

## API key

Ven needs your own CurseForge API key.

1. Sign in with Google at [console.curseforge.com](https://console.curseforge.com) and open **API keys**.
2. Copy your key.
3. In the Modrinth App, click the puzzle-piece button above **Settings** and paste the key into **CurseForge API key**.

The key is stored encrypted on your pc and is only sent to CurseForge.

## Use

- **Browse:** in Discover content, set **Platform** to **CurseForge** and install like any Modrinth project. Modpacks get their own instance.
- **Project pages:** click a result to open its page in the launcher.
- **Updates:** CurseForge files on an instance's **Content** tab get the launcher's update button, **Switch version** and **Update all**.
